## Package Installation

Packages are managed via [Wally](https://github.com/UpliftGames/wally), a package manager for Roblox.

```bash
# Install all dependencies
wally install

# Add a new package
wally add <author>/<package>@<version>
```

See `wally.toml` in the project root for the full dependency manifest.
